A load counts as unbilled/unpaid once it has been delivered but is sitting in any status other than “Invoiced” or “Complete” — loads still open, covered, dispatched, or in transit are excluded entirely. Use the status filter above to narrow to one post-delivery status at a time. Status, carrier, delivery-date, and rate field names are best-effort (see PRE_DELIVERY_STATUSES, BILLED_STATUSES, STATUS_KEYS, CARRIER_KEYS, DELIVERY_DATE_KEYS, LOAD_RATE_KEYS in generate_report.py) — if a chart below shows “field not found,” check the Unbilled Loads tab for the real column name and have it added to the script. To refresh: run python generate_report.py, then python build_dashboard.py alvys_report.json, then republish this page.
